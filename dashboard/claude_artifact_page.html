How each metric is defined
Leg
One trip's movement from a source facility to a destination facility. Raw checkpoint rows are rolled up to legs.
Planned time (OSRM)
Drive time estimated by the OSRM routing engine for the leg's route, as provided in the dataset.
Within SLA
Actual transit time no more than the SLA factor times the planned time. The factor is a project setting (config.py), since the data has no promised date.
Actual vs planned time
Actual transit minutes divided by OSRM minutes. Medians are used because a few legs run over 10× plan.
Time at facilities
Start-scan-to-end-scan minutes minus actual transit minutes: loading, waiting and handling.
Avg extra min
Average actual transit minutes minus planned minutes.
Source
Delhivery's public trip dataset (Sep 12 – Oct 3, 2018), as used in public analytics case studies. Facility city, state and type are parsed from facility names.
